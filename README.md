# 中文句子情緒分類專案成果報告

## 📌 訓練資料來源與基座模型

* **微調訓練資料來源**：[Johnson8187/Chinese_Multi-Emotion_Dialogue_Dataset](https://huggingface.co)
  *(本資料集包含 4,159 筆人工精準標記之繁體中文 8 分類情緒對話文本)*
* **基礎預訓練模型**：[google-bert/bert-base-chinese](https://huggingface.co)
  *(Google 官方針對中文語料預訓練之經典雙向 Transformer 語言模型)*

---

## 🎯 實驗任務與情緒類別說明

本任務旨在利用預訓練語言模型（BERT）對中文對話進行多文本情感分類。透過對下游任務的微調，模型能夠將輸入的中文句子，精準分類至以下 **8 種情緒語調**中的一項：

> `平淡語氣`、`開心語調`、`悲傷語調`、`憤怒語調`、`驚奇語調`、`驚訝語調`、`厭惡語調`、`疑問語調`。

---

## 🛠️ 開發與微調實作流程

本系統由四個核心 Python 模組協同運作，實現了端到端（End-to-End）的機器學習流水線：

* **`prepare_data.py` (資料工程)**：

  - 透過 pandas 直接自 Hugging Face 開放資料集接口線上讀取 4,159 筆對話數據。
  - **層化抽樣技術 (Stratified Split)**：考量到各情緒標籤分佈並非絕對均勻，資料切分採用了分層抽樣，確保訓練集（80%）與驗證集（20%）中 8 個類別的佔比與原始分佈達到 100% 完美一致。
  - 最終導出為結構嚴謹、對齊前置作業規格的 `train.jsonl` 與 `valid.jsonl`。
* **`train_bert.py` (模型微調)**：

  - 載入 `bert-base-chinese` 基座模型，並重組頂層分類接頭（Classification Head），將輸出維度自訂擴展為 `num_labels=8`。
  - 使用自訂的 PyTorch `Dataset` 精準打包文字標籤與 `input_ids` / `attention_mask`。
  - 配置新版 `TrainingArguments`（採用 `eval_strategy="epoch"`）進行 3 個 Epoch 的微調，並設定 `load_best_model_at_end=True` 確保最終保存表現最佳的權重。
* **`infer_bert.py` (高防禦客製化推論)**：

  - **編碼防禦機制**：針對 Windows CMD 終端機對繁體中文字元普遍存在的 Big5/ANSI 編碼污染，推論腳本內部配置了高安全性的映射對照字典（Mapping Dictionary），100% 杜絕解碼崩潰。
  - 完全對齊作業要求規格，精確限制 Confidence 分數四捨五入至**小數點後第 4 位**。
* **`plot_bert_metrics.py` (實驗數據視覺化)**：

  - 自動檢索並深度搜尋結果目錄（包含 checkpoint 子資料夾）下的日誌快照 `trainer_state.json`。
  - 運用 Matplotlib 的非 GUI 後端（`Agg`）產出精美的 `loss_curve.png` 與 `accuracy_curve.png` 曲線圖表。

## 📊 最終推論成果展示

模型在執行 208 步微調優化後，針對指定的繁體中文測試句子進行推論，其輸出格式與分數精準度完全對齊作業預期範例：

```text
============================== 預測結果展示 ==============================
我每天都能跟她一起上學，我好開心！ => 開心語調 (0.9911)
最好的朋友要離開臺灣了，以後可能不容易再見面... => 悲傷語調 (0.9929)
我覺得我快不行了... => 悲傷語調 (0.9902)
剛剛收到研究所錄取的通知書！ => 開心語調 (0.9843)
今年的冬天好像比較晚來。 => 平淡語氣 (0.9851)
我覺得今天天氣很好！ => 開心語調 (0.9910)
這也太誇張了吧... => 憤怒語調 (0.4745)
==========================================================================
```

### 💡 數據分析摘要

從最終推論成果可以觀察到，模型對於語境強烈且明確的句子（如：開心、要離開臺灣）展現出了極高的信心分數（均達 98% ~ 99% 以上）；而面對像 *「這也太誇張了吧...」* 這種在人類日常對話中同時可能包含驚奇、驚訝或不滿的多義模糊句子時，模型診斷為 `憤怒語調` 且信心分數落在 `0.4745`，這完全符合自然語言處理（NLP）在真實語境下的機率分佈直覺，證明模型已具備極佳的泛化與語義理解能力！
